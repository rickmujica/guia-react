React 19.3 incorpora **animaciones** de forma nativa. `<ViewTransition>` usa la [View Transitions API](https://developer.mozilla.org/es/docs/Web/API/View_Transition_API) del navegador para animar componentes cuando entran, salen, se mueven o cambian, y React decide cuándo y qué animar.

```tsx
import { ViewTransition, startTransition } from 'react'

<ViewTransition>
  <JobCard job={job} />
</ViewTransition>
```

## Qué activa una animación

Esta es la regla más importante: **un `setState` común no anima nada**. Solo animan los cambios que ocurren dentro de:

- una **Transition** (`startTransition`, `useTransition`, una Action, un `<form action>`),
- un **`<Suspense>`** que revela su contenido,
- o un **`useDeferredValue`**.

Tiene sentido: las transiciones son las actualizaciones "no urgentes", y una animación de 300 ms es justamente algo que no querés en una tecla del input.

## Los cuatro tipos de animación

| Tipo | Cuándo se activa |
| --- | --- |
| `enter` | El `<ViewTransition>` se monta en la transición. |
| `exit` | El `<ViewTransition>` se desmonta en la transición. |
| `update` | Cambia algo adentro, o el boundary cambia de tamaño o posición (por ejemplo, al reordenar una lista). |
| `share` | Un `<ViewTransition>` con `name` se desmonta y otro con el mismo `name` se monta: "elemento compartido" que vuela de un lugar a otro. |

Por defecto todas hacen un **cross-fade**. Para personalizarlas, pasás una **clase** a cada prop (`enter="vt-slide-in"`) y la estilás con los pseudo-elementos de la View Transitions API.

## Transition Types: animar distinto según la causa

Una misma actualización puede necesitar animaciones distintas según **por qué** ocurrió: avanzar o retroceder en un carrusel, navegar hacia adelante o hacia atrás. `addTransitionType` le agrega un "tipo" a la transición y `<ViewTransition>` acepta un objeto que mapea cada tipo a una clase.

## Buenas prácticas

- **Respetá `prefers-reduced-motion`**: React no desactiva las animaciones solo. Agregá una media query que las apague (mirá el final de `view-transitions.css`).
- **No llames a `document.startViewTransition`** por tu cuenta: React lo hace por vos y coordina las animaciones. Si ya usabas la API a mano, migrá a `<ViewTransition>`.
- **Usá `name` solo para elementos compartidos.** Para todo lo demás, React genera nombres únicos automáticamente.
- **Animaciones con JavaScript**: los eventos `onEnter`, `onExit`, `onUpdate` y `onShare` te dan acceso a la animación para controlarla con la Web Animations API.

<Nota title="Soporte">
Funciona en los navegadores con View Transitions de mismo documento (Chrome, Edge, Safari y Firefox recientes). Donde no hay soporte, el cambio se aplica sin animación: nada se rompe. Por ahora solo funciona en el DOM, no en React Native.
</Nota>
