<Nota title="Cómo elegir una librería">
Antes de instalar algo, mirá en [reactnative.directory](https://reactnative.directory): si soporta la Nueva Arquitectura (obligatoria desde el SDK 55), si anda en Expo Go, cuándo fue el último release y cuántas descargas tiene. Y siempre `npx expo install`, para que elija la versión compatible con tu SDK.
</Nota>

<Ojo title="Compras dentro de la app: no podés usar Stripe para todo">
Si vendés algo **digital que se usa dentro de la app** (una suscripción premium, monedas, desbloquear funciones), Apple y Google exigen usar **su** sistema de pagos (In-App Purchase / Google Play Billing), que se queda con un 15–30 %. Stripe es para cosas físicas o servicios fuera de la app (un envío, un turno, una entrada). Lo vemos en [requisitos](#/requisitos). Por eso existe RevenueCat: maneja las suscripciones de las dos tiendas con una sola API.
</Ojo>

## Traducciones, por ser lo más pedido

```ts
// src/lib/i18n.ts
import { getLocales } from 'expo-localization'
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'

i18n.use(initReactI18next).init({
  resources: {
    es: { translation: { ofertas: 'Ofertas', guardar: 'Guardar' } },
    en: { translation: { ofertas: 'Jobs', guardar: 'Save' } },
  },
  lng: getLocales()[0]?.languageCode ?? 'es',  // el idioma del teléfono
  fallbackLng: 'es',
})

// En un componente
const { t } = useTranslation()
<Text>{t('ofertas')}</Text>
```

Para que la tienda muestre tu app como disponible en varios idiomas, también se traducen el nombre de la app y los textos de los permisos, con la clave `locales` de `app.json` (un JSON por idioma).
