## Preguntas de entrevista

<Entrevista title="¿React Native es una WebView?">
No. Los componentes se traducen a vistas nativas (UIView, android.view.View). El JavaScript corre en Hermes y se comunica con lo nativo vía JSI. Una WebView (como Cordova o Ionic con Capacitor) dibuja HTML.
</Entrevista>

<Entrevista title="¿Qué es la Nueva Arquitectura?">
JSI reemplaza al bridge asincrónico: JavaScript llama a C++ directo. Fabric es el renderer nuevo (soporta las features concurrentes de React y layout sincrónico), TurboModules carga los módulos nativos a demanda, y Codegen genera los tipos entre JS y nativo. Es la única arquitectura desde el SDK 55.
</Entrevista>

<Entrevista title="¿Expo Go o development build? ¿Qué es prebuild?">
Expo Go trae compiladas solo las librerías del Expo SDK: sirve para aprender y prototipar. Un development build es tu propia versión con tus librerías nativas, y es lo que se usa en proyectos reales. Prebuild (CNG) genera las carpetas `ios/` y `android/` desde `app.json` y los config plugins; no se editan a mano ni se suben a git.
</Entrevista>

<Entrevista title="¿Cómo optimizás el rendimiento?">
Medir primero en una build de release y en un Android barato. Listas con FlashList o Legend List, filas livianas y memoizadas (el React Compiler lo hace solo), imágenes con expo-image y tamaño fijo, animaciones en el hilo de UI con Reanimated, selectores en Zustand para no re-renderizar de más, no bloquear el hilo de JS, y cargar lo mínimo al arrancar.
</Entrevista>

<Entrevista title="¿Por qué se traba una animación?">
Porque depende del hilo de JavaScript y ese hilo está ocupado. La solución: Reanimated (worklets en el hilo de UI) o `useNativeDriver: true` con Animated, y Gesture Handler para gestos.
</Entrevista>

<Entrevista title="¿Dónde guardás el token? ¿Y los secretos?">
El token en SecureStore (Keychain / Keystore). Los secretos de la app no van en la app: todo lo que está en el bundle se puede leer, incluidas las variables `EXPO_PUBLIC_`. Van en el backend.
</Entrevista>

<Entrevista title="¿Qué se puede actualizar por OTA?">
Todo lo que es JavaScript, estilos e imágenes, con EAS Update, a las builds con la misma runtime version. Lo nativo (librerías nativas, permisos, ícono, SDK) necesita una build nueva y pasar por la tienda. Y siempre respetando que no cambie el propósito de la app.
</Entrevista>

<Entrevista title="¿Cómo manejás la navegación y la autenticación?">
Expo Router: rutas como archivos, Stack y pestañas nativas, parámetros tipados con typed routes. Para el login, `Stack.Protected` con un guard según haya token; el token en SecureStore, hidratado con el splash visible para que no parpadee el login; y el backend valida el token en cada pedido.
</Entrevista>

<Entrevista title="¿Qué diferencias hay entre iOS y Android que tengas que manejar?">
El botón "atrás" de Android (onRequestClose en modales), el gesto de volver de iOS, los permisos (en iOS solo se pregunta una vez), los textos de permisos en iOS, las sombras (hoy `boxShadow` unifica), las fuentes, el teclado (`KeyboardAvoidingView` con `behavior` distinto), las notificaciones (canales en Android), y los requisitos de cada tienda.
</Entrevista>
